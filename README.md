# Live Tickets

Dark, responsive affiliate ticket portal for sports, concerts and live events.

## Hosting

GitHub Pages publishes `index.html` from the main branch through the included workflow.
The page is self-contained; its illustrative AI-generated images are embedded.

## Updating

Use the local editable version of the portal to update menus, text, media and YouTube links. Export the public HTML, rename it `index.html`, and replace this repository's file. Commit to redeploy.

Three match video slots and two upcoming concert video slots are initially empty. No actual matches, show dates, inventory or prices are fabricated. Automatic event ingestion requires a configured supplier feed; the current affiliate button opens the supplier catalogue.

## Affiliate disclosure

Purchases through affiliate links may earn the operator a commission. Availability, prices and purchase terms are determined by suppliers. This is an independent affiliate portal.
